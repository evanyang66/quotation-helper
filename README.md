# 报价单助手 / Quotation Helper

给自行接单用户使用的轻量报价工具：在一个可离线运行的 HTML 页面里快速制作报价，并按自己的业务调整物料、价格和模板。无需安装、无需 Office，双击 `报价单助手.html`，用 Edge / Chrome 打开即可。

## 为什么做这个项目

自行接单时，报价往往要反复填写物料与数量、修改价格、计算合计，再整理成可以交付给客户的格式。不同业务的项目内容和报价习惯也不完全一样，固定表格不一定顺手。

报价单助手把这些步骤集中到一个简单的本地页面中，让用户维护自己的物料和模板、复用已有报价，再按需要导出或打印。现有示例主要围绕监控、布线、门禁等安装服务，也可以按业务调整报价内容。

## 解决什么问题

- **快速出单**：选择物料，填写数量和单价，自动汇总行金额、分组小计与报价合计。
- **适应自己的业务**：可调整物料、单位及对应单价、项目说明、选配项和分组，并保存自建模板；提供多种列结构与版式。
- **减少重复填写**：在浏览器本地保存报价、复制历史单据，复用常见项目内容。
- **方便交付客户**：导出带图片的 Excel 报价单，或通过浏览器打印、另存 PDF。

## 主要功能

- 管理物料库、套用模板并填写报价明细。
- 编辑数量、单价、分组、小计和选配项目。
- 粘贴产品图片，导出 Excel、打印或保存 PDF。
- 在浏览器本地保存数据，并通过 JSON 备份与恢复。

## 使用与备份

先读 [使用前必读](使用前必读.txt)，完整操作见 [使用说明](使用说明.md)，换电脑前请查看 [迁移说明](换电脑使用说明.md)。浏览器数据不会自动同步。当前 JSON 备份包含当前单据、版式与自建模板，不等于物料库和全部历史单据的完整备份；清理浏览器或换电脑前，请核对需要另行保留的内容。

## 源码与构建

`src/01_head.html`、`src/02_data.js`、`src/03_xlsx.js`、`src/04_app.js` 组成单文件入口。需要重新构建时安装 Node.js，再用 Git Bash / WSL 执行：

```bash
bash src/build.sh
```

`downloads/quotation-helper.zip` 包含可直接打开的 HTML、源码和使用说明，不包含个人单据或浏览器数据。
